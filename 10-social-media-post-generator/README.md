# Social Media Post Generator

## Overview

The Social Media Post Generator is a Python application that uses Artificial Intelligence to help users create social media content. It generates text based on user-provided topics and preferences.

## Features

- Generate social media post drafts.
- Customize content using prompts.
- Explore different writing styles and tones.
- Simplify social media content creation.

## Technologies Used

- Python
- Streamlit
- LangChain
- Groq API
- Large Language Models (LLMs)

## Project Structure

```text
10-social-media-post-generator/
├── social_media_post_generator.py
├── README.md
└── requirements.txt
```

## Installation

```bash
pip install -r requirements.txt
```

## Configuration

Configure the Groq API key using an environment variable expected by the application. Do not commit API keys or `.env` files.

## Run the Application

```bash
streamlit run social_media_post_generator.py
```
