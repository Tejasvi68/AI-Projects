# Mini AI Agent

## Overview

The Mini AI Agent is a Python-based project that explores how an AI agent can use language models and tools to respond to user requests. It demonstrates introductory concepts in tool-assisted AI workflows.

## Features

- Process user requests using an LLM.
- Explore tool-assisted AI interactions.
- Demonstrate agent workflows.
- Practice integrating external tools with language models.

## Technologies Used

- Python
- LangChain
- Groq API
- Large Language Models (LLMs)

## Project Structure

```text
06-tool-using-mini-agent/
├── miniagent.py

```

## Installation

```bash
pip install -r requirements.txt
```

## Configuration

Configure the API key required by the application using an environment variable. Do not commit credentials to GitHub.

## Run the Application

```bash
python miniagent.py
```

## Learning Objectives

- Understand the fundamentals of AI agents.
- Explore tool integration with LLMs.
- Learn about agent execution workflows.
- Practice building AI applications in Python.
