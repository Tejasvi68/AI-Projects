# Movie Dialogue Assistant

## Overview

The Movie Dialogue Assistant is a Python application that explores the use of Artificial Intelligence for movie-related dialogue generation. It uses natural-language prompts to help generate creative text associated with movies and fictional scenarios.

## Features

- Generate movie-related dialogue using AI.
- Explore creative text generation.
- Process user prompts through a language model.
- Provide an interactive interface.

## Technologies Used

- Python
- Streamlit
- LangChain
- Groq API
- Large Language Models (LLMs)

## Project Structure

```text
07-movie-dialogue-assistant/
├── movie_dialog.py
├── README.md

```

## Installation

```bash
pip install -r requirements.txt
```

## Configuration

Set the API key required by the application using an environment variable. Keep credentials private.

## Run the Application

```bash
streamlit run movie_dialog.py
```
