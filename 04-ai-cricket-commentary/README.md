# AI Cricket Commentary Generator

## Overview

The AI Cricket Commentary Generator is a Python application that uses Artificial Intelligence to generate cricket commentary from match-related inputs. It demonstrates how language models can create engaging sports commentary from a given match situation.

## Features

- Generate cricket commentary using AI.
- Create descriptive match updates from supplied inputs.
- Customize commentary using match details.
- Generate natural-language sports content.

## Technologies Used

- Python
- Streamlit
- LangChain
- Groq API
- Large Language Models (LLMs)

## Project Structure

```text
04-ai-cricket-commentary/
├── cricket_commentary.py

```

## Installation

```bash
pip install -r requirements.txt
```

## Configuration

Set the required Groq API key as an environment variable. Keep credentials private and never commit them to GitHub.

## Run the Application

```bash
streamlit run cricket_commentary.py
```
